# Beyond Realms

Beyond Realms is a Fabric 26.2 adventure/progression mod built around four dangerous dimensions, realm-exclusive resources, custom creatures, bosses, relics and Godforged end-game equipment.

## Realms

- **Dinosaur Wilds / Primeval Jungle** — dense prehistoric wilderness, Primeval Amber and prehistoric creatures.
- **Paranormal Realm / Haunted Wastes** — spectral wastes filled with Wraithstone and Grave Wraiths.
- **Spider Caves / Brood Hollows** — suffocating underground caverns rich in Brood Crystal and swarming with Broodlings.
- **Titan Expanse / Void Frontier** — hostile void islands containing Voidium and Void Stalkers.

## Amber genetics and dinosaur creation

Primeval Amber is the heart of the dinosaur progression loop:

1. Mine **Primeval Amber Ore** in Dinosaur Wilds.
2. Process Primeval Amber with the **Amber Extractor** to recover one of seven dinosaur DNA fragment types.
3. Combine three matching DNA fragments using the **Genome Sequencer** to create a completed genome.
4. Use the **Gene Splicer** to combine compatible genomes or cross-realm biological materials into hybrids.
5. Feed a completed genome and a vanilla egg into the **Egg Incubator** to create an incubated dinosaur egg.
6. Use the incubated egg in the world to hatch the creature.

Standard genomes currently include Raptor, Tyrannosaur, Triceratops, Dilophosaurus, Spinosaurus, Ankylosaurus and Carnotaurus.

Hybrid genomes include **Tyrant Raptor**, **Venomjaw Rex**, **Spectral Raptor**, **Webfang**, **Void Rex** and the end-game **Apex Chimera**. Cross-realm hybrids use materials such as Ectoplasm, Brood Venom Glands and Void Hearts, tying the genetics system into the other realms.

## Cross-realm progression

Each realm provides an ore/material and a creature drop. Survivors who collect all eight realm components plus a Titan Core can craft the **Nexus Core**, a powerful late-game relic that represents mastery of all four realms. The Nexus Core is also required for the Apex Chimera hybrid.

The project also includes Eternium progression, rift keys, boss sigils, trophy heads, ability relics and Godforged equipment.

## Custom world

A dedicated handcrafted Beyond Realms adventure map is planned for a later phase. The mod itself remains playable in normal generated worlds and is being built so a future official map can layer story, structures, dungeons and streamer-friendly progression on top.
